# Abed FX portfolio refresh

This version uses React + Vite with portfolio/profile copy stored in `src/content.json` and styles/effects in `src/styles.css`.


## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Production build
Run `npm run build`. The production website is created in `dist/`.


## Included changes
- Updated portfolio and Behance wording; removed the requested phrases.
- About section no longer says “Hello, world”.
- Avatar frame is 128×128px with 15px rounded corners.
- Animated repeating grid, soft purple bloom, CRT scanlines/vignette.
- Hover/drag cursor light over interactive cards.
- Scroll reveal with blur/fade and edge masking.
- Responsive layout and reduced-motion support.
